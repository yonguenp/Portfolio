ShapeKit

Sprite-free UI shapes for uGUI. Rounded rectangles, pills and circles with outline, gradient and drop shadow, all on one component.

Asset Store page (soon) Documentation
  • Per-corner radius, pill and circle modes
  • Outline, linear gradient, drop shadow, soft glow
  • One shared material, so shapes batch together
  • Taps on transparent corners pass through
  • Safe area fitter and press feedback for mobile

ShapeKit documentation

1. Install

Import from the Asset Store, or copy the ShapeKit folder into Packages/. Requires Unity 2021.3+ and uGUI.

2. Create

GameObject › UI › ShapeKit › Shape Image or Pill Button. Pick a preset at the top of the inspector.

3. Customize

Adjust Shape, Fill, Outline and Shadow sections, or set the same properties from code on ShapeImage.

Safe area

Add SafeAreaFitter to a full-screen child of the canvas and place UI inside it. Each edge can be toggled.

Press feedback

Add ShapePressFeedback to a button to scale it down and tighten its shadow while pressed.

Demo

Import the Demo sample, add ShapeKitDemo to an empty GameObject and press Play. Use the Frame Debugger to inspect batching.
