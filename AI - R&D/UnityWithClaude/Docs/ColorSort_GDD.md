## 2. 핵심 메커니즘

### 기본 규칙
- 여러 개의 **튜브(병)**에 색깔 블록들이 섞여 있음
- 블록을 튜브에서 튜브로 **이동**시켜 같은 색끼리 한 튜브에 모으면 클리어
- 튜브 맨 위 블록만 이동 가능
- 이동 대상 튜브의 맨 위 색상이 같거나 비어있을 때만 이동 가능
- 튜브 용량은 **4칸** 고정

### 승리 조건
- 모든 튜브가 단일 색상으로 가득 찼거나 비어 있을 때

### 조작
- 출발 튜브 탭 → 도착 튜브 탭 (2탭 방식)
- 이동 불가 시 시각/음향 피드백

---

## 3. 게임 구성요소

### 튜브 구성 (난이도별)

| 난이도 | 색상 수 | 튜브 수 | 빈 튜브 수 |
|--------|---------|---------|-----------|
| Easy | 3 | 5 | 2 |
| Normal | 5 | 7 | 2 |
| Hard | 7 | 9 | 2 |
| Expert | 9 | 11 | 1 |

### 특수 요소 (후반 도입)
- **잠금 블록**: 특정 조건을 만족해야 이동 가능
- **폭탄 블록**: 같은 색 블록 전체 제거
- **무지개 블록**: 모든 색에 매칭 가능

---

## 4. 레벨 구성

```
스테이지 1~20   : 튜토리얼 + Easy
스테이지 21~60  : Normal
스테이지 61~120 : Hard
스테이지 121~   : Expert (무한 생성 또는 주기적 추가)
```

- **초기 출시 목표**: 120 레벨
- 레벨 데이터는 JSON으로 관리 (코드 수정 없이 추가 가능)
- 클리어 불가능한 레벨 방지를 위해 역방향 생성 알고리즘 사용

## 5. UI / 씬 구성

```
SplashScene
    └─ 로고 페이드인/아웃
TitleScene
    ├─ 게임 시작 / 계속하기
    ├─ 설정 (BGM, SFX)
    └─ 크레딧
LobbyScene (스테이지 선택)
    ├─ 스테이지 그리드 (클리어/잠금/현재 표시)
    └─ 코인 표시
GameScene
    ├─ 튜브 배치 영역
    ├─ 상단 HUD (레벨, 이동 횟수, 힌트)
    ├─ 되돌리기 버튼
    └─ 일시정지 팝업
ResultPopup
    ├─ 클리어 시: 별 애니메이션, 다음 레벨
    └─ 실패 시: 재시도, 힌트 사용
```

## 6. 수익화 전략

### 광고 (메인 수익)

| 광고 유형 | 노출 시점 | 빈도 |
|----------|---------|------|
| 인터스티셜 | 레벨 클리어 후 | 3레벨마다 1회 |
| 리워드 광고 | 힌트 획득 / 추가 이동 / 되살리기 | 유저 선택 |
| 배너 광고 | 로비 화면 하단 | 상시 |

### IAP (보조 수익)

| 상품 | 가격 | 내용 |
|------|------|------|
| 광고 제거 | ₩4,900 | 인터스티셜/배너 제거 |
| 힌트 팩 소 | ₩1,200 | 힌트 10개 |
| 힌트 팩 대 | ₩4,900 | 힌트 50개 |
| 스타터 팩 | ₩2,900 | 힌트 30개 + 광고 1주 제거 |

### 무료 재화 지급
- 첫 실행: 힌트 5개 제공
- 매일 접속: 힌트 1개
- 레벨 10개 클리어마다: 힌트 2개

## 7. 기술 아키텍처

```
Assets/
├─ Scenes/          SplashScene, TitleScene, LobbyScene, GameScene
├─ Scripts/
│   ├─ Core/        GameManager, LevelManager, ScoreManager
│   ├─ Gameplay/    TubeController, BlockController, LevelSolver
│   ├─ UI/          LobbyUI, GameUI, ResultPopup, ShopUI
│   ├─ Data/        LevelData, UserData, SaveManager
│   └─ Ads/         AdManager (래퍼 클래스)
├─ Data/
│   └─ Levels/      level_001.json ~ level_120.json
├─ Prefabs/         Tube, Block, Popup
└─ Resources/       Fonts, Sprites, Audio
```
