# ShapeKit Unity 테스트 체크리스트

이 패키지는 Unity 없이 작성됐습니다. 셰이더 계산은 Python으로 옮겨 그려서 확인했지만(`preview.png`),
C# 컴파일과 실제 렌더링은 Unity에서 처음 확인하는 것입니다. 아래 순서대로 확인하고, 문제가 생기면
**Console 오류 전문**이나 **스크린샷**을 보내 주세요.

## 1. 설치와 컴파일
- [ ] Unity 2021.3 이상 빈 프로젝트의 `Packages/` 폴더에 `ShapeKit` 폴더를 복사
- [ ] Console에 컴파일 오류가 없는지 확인
- [ ] Package Manager → ShapeKit → Samples → **Demo Import**

## 2. 데모 화면 (`preview.png`와 비교)
- [ ] 빈 씬에 빈 GameObject → `ShapeKitDemo` 추가 → Play
- [ ] 카드 그림자가 부드럽게 보이는지
- [ ] 원형 아바타에 흰 테두리와 그림자가 있는지
- [ ] 파란 말풍선의 **왼쪽 아래 모서리만** 각져 있는지
- [ ] 그라데이션 사각형 4개 방향이 →, ↗, ↑, ↖ 순서인지
- [ ] Outline 버튼이 속이 비고 테두리만 보이는지
- [ ] 버튼을 누르면 살짝 작아지고 그림자가 줄어드는지, 클릭 로그가 찍히는지
- [ ] Game 뷰 해상도를 바꿔도 가장자리가 선명한지

## 3. 성능 (핵심 판매 포인트)
- [ ] Window → Analysis → **Frame Debugger** → Enable
- [ ] 스트레스 테스트 도형 300개가 **드로우콜 1~2개**로 묶이는지 (텍스트, 아바타는 별도)
- [ ] `m_StressCount`를 2000으로 올려 프레임 확인

## 4. 호환성
- [ ] Color Space를 Gamma / Linear 둘 다 바꿔서 색이 Image와 같은 톤인지
- [ ] `Mask`, `RectMask2D` 안에서 잘리는지
- [ ] `CanvasGroup` alpha 0.5에서 채움, 테두리, 그림자가 함께 반투명해지는지
- [ ] Button의 Color Tint 전환(눌림 색)이 적용되는지
- [ ] URP 프로젝트에서도 같은 결과인지
- [ ] Device Simulator(노치 기기)에서 `SafeAreaFitter`가 안전 영역에 맞춰지는지

## 5. 에디터 사용성
- [ ] GameObject → UI → ShapeKit 메뉴 3개가 동작하는지
- [ ] 인스펙터 프리셋 버튼 5개, Ctrl+Z 되돌리기
- [ ] 여러 개 선택해서 동시에 수정되는지
