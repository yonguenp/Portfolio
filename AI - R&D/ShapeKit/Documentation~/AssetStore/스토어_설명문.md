## Title
ShapeKit - Sprite-free UI Shapes

## Summary (short description)
Rounded rectangles, pills and circles for uGUI without sprites. Per-corner radius, outline, gradient and drop shadow on one component, batched with a single material.

## Description

**Stop slicing sprites for every rounded button.**

ShapeKit draws UI shapes procedurally, so you can change corner radius, outline, gradient and shadow right in the inspector, at any resolution, with zero texture memory.

**Why ShapeKit**
• **Batches everything.** All shape parameters live in vertex data, so shapes with different radii, colors, outlines and shadows still batch together with one shared material.
• **All-in-one component.** Per-corner radius, pill and circle modes, outline, linear gradient, drop shadow, edge softness and circular sprite crop on a single ShapeImage.
• **Shape-accurate touch.** Taps on the transparent rounded corners pass through, so tightly packed round buttons never steal each other's input.
• **Crisp at any scale.** Edges are computed per pixel and anti-aliased for the current screen resolution.
• **Mobile ready.** Includes SafeAreaFitter for notches and ShapePressFeedback for tactile "push" buttons.
• **Fast workflow.** One-click presets (Card, Pill, Outline, Avatar, Glow), grouped inspector sections, multi-object editing and GameObject menu shortcuts.
• **Plays well with others.** Works with Mask, RectMask2D, CanvasGroup, Button color transitions, Input System and the legacy Input Manager.

**Included**
• ShapeImage, SafeAreaFitter and ShapePressFeedback components
• Single UI shader (Built-in, URP and HDRP)
• Runtime demo with a batching stress test
• Full C# source code and documentation

**AI disclosure**
Parts of this package's code and documentation were created with the help of AI tools and were reviewed and tested by the publisher.

## Technical details
• Unity 2021.3 or later, uGUI (Unity UI)
• Built-in Render Pipeline, URP and HDRP
• Screen Space Overlay and Screen Space Camera canvases
• Works with both Active Input Handling modes (Input System package and legacy Input Manager)
• Shapes using different sprites batch separately (same rule as Image)
• RectMask2D softness is not applied (hard clipping works)
• Full source code, namespaced (ShapeKit) with assembly definitions
