# ShapeKit 에셋스토어 업로드 가이드

계정 가입, 정산 정보, 최종 제출은 본인 인증이 필요해서 직접 하셔야 합니다.
스토어 설명문과 이미지는 이 폴더에 준비해 두었습니다.
Unity 정책과 화면 구성은 자주 바뀌므로, 각 단계에서 Publisher Portal에 표시되는 최신 안내를 우선하세요.

## 0. 업로드 전에 꼭 정할 것

- [ ] **Frame Debugger로 드로우콜 직접 확인.** 스토어 문구의 "1 material · 1 draw call"은 핵심 판매 포인트입니다. 실제로 확인되지 않으면 문구를 고쳐야 합니다.
- [ ] **저장소 공개 여부 정리.** 지금 코드는 포트폴리오 저장소에 있습니다. 공개 저장소라면 무료로 받을 수 있는 코드를 파는 셈이 됩니다. 판매 전에 비공개 저장소로 옮기고 포트폴리오에서는 빼는 것을 권합니다.
- [ ] **이름 확정.** `ShapeKit`은 임시 이름입니다. 스토어에서 같은 이름이 있는지 검색해 보세요. 이름을 바꾸면 `make_store_images.py`의 `NAME`을 고치고 다시 실행하면 이미지가 새로 만들어집니다.
- [ ] **AI 사용 고지.** Asset Store는 AI 도구로 만든 콘텐츠의 고지를 요구합니다. 설명문 마지막 문단에 포함해 두었습니다. 제출 양식에 관련 항목이 있으면 그대로 체크하세요.
- [ ] **가격.** 경쟁 에셋이 $10~22라서 출시가 $12.99, 출시 할인 $9.99를 권장합니다. 최소 가격 규정은 포털에서 확인하세요.

## 1. 퍼블리셔 계정 만들기 (1회)

1. Unity ID로 **Publisher Portal**(publisher.unity.com)에 로그인하고 퍼블리셔 프로필을 만듭니다.
   - 퍼블리셔 이름, 웹사이트(포트폴리오 GitHub Pages 사용 가능), 지원 이메일을 입력합니다.
2. **세금 정보**를 등록합니다. 한국 거주자는 W-8BEN 양식으로 미국 원천징수 조세조약 혜택을 받을 수 있습니다.
3. **정산 방법**(PayPal 또는 은행 계좌)을 등록합니다.

## 2. 업로드용 Unity 프로젝트 준비

1. 지원 최소 버전인 **Unity 2021.3 LTS**로 빈 프로젝트를 만듭니다. 최소 버전에서 업로드해야 그 버전부터 호환으로 표시됩니다.
2. `ShapeKit` 폴더를 프로젝트의 `Packages/` 폴더에 복사합니다. Unity가 `.meta` 파일을 생성합니다.
3. Package Manager에서 **Asset Store Publishing Tools**(`com.unity.asset-store-tools`)를 설치합니다.
4. 컴파일 오류가 없는지, 데모가 동작하는지 한 번 더 확인합니다.

## 3. 포털에서 패키지 초안 만들기

Publisher Portal → **Create Package**에서 아래 내용을 입력합니다. `스토어_설명문.md`에서 복사해 쓰면 됩니다.

| 항목 | 값 |
| --- | --- |
| Category | Tools / GUI |
| Title | ShapeKit - Sprite-free UI Shapes |
| Summary | 짧은 설명 (설명문 파일 참고) |
| Description | 긴 설명 (설명문 파일 참고) |
| Technical details | 설명문 파일 참고 |
| Keywords | 설명문 파일 참고 |
| Price | $12.99 |

**이미지 업로드** (이 폴더의 파일)

| 용도 | 파일 | 크기 |
| --- | --- | --- |
| Icon | `icon_160x160.png` | 160×160 |
| Card | `card_420x280.png` | 420×280 |
| Cover | `cover_1950x1300.png` | 1950×1300 |
| Social | `social_1200x630.png` | 1200×630 |
| Screenshots | `screenshot_1~4_*.png` | 1950×1300 |

포털이 요구하는 크기가 다르면 알려 주세요. 스크립트로 바로 다시 만들 수 있습니다.

> 스크린샷은 셰이더 계산을 옮긴 렌더러로 만든 그림입니다. 심사와 구매자 신뢰를 위해 **Unity 에디터에서 찍은 실제 스크린샷**(인스펙터 화면, Frame Debugger 드로우콜 화면)을 2~3장 추가하는 것을 강하게 권합니다.

## 4. 에디터에서 업로드

1. 메뉴 **Tools → Asset Store → Uploader**를 열고 퍼블리셔 계정으로 로그인합니다.
2. 방금 만든 초안 패키지를 선택합니다.
3. 업로드 방식은 **Local UPM Package**(또는 Package)를 고르고 `Packages/ShapeKit`을 지정합니다.
   - 이 방식을 쓸 수 없는 버전이면 **Assets 폴더 방식**으로 업로드합니다. 이때는 `ShapeKit` 폴더를 `Assets/ShapeKit`으로 옮기고, `Samples~` 폴더 이름을 `Samples`로 바꿔야 Unity가 가져옵니다.
4. **Validate**를 먼저 실행해 경고를 확인하고 고칩니다. 결과를 저에게 보내 주시면 같이 고치겠습니다.
5. **Upload**를 누릅니다.

## 5. 제출과 심사

1. 포털에서 미리보기를 확인한 뒤 **Submit for Review**를 누릅니다.
2. 심사는 보통 몇 영업일에서 몇 주까지 걸립니다.
3. 반려되면 사유가 메일로 옵니다. 그대로 보내 주시면 수정하겠습니다.

## 6. 출시 후

- **세일 이벤트 신청:** 포털에서 Unity 정기 세일 참여 신청을 열어 둡니다.
- **홍보:** 설명문 하단의 영문 소개글을 Reddit r/Unity3D, X 등에 올립니다.
- **문의 응대:** 리뷰와 문의는 빠르게 답합니다. 답변 초안은 제가 쓸 수 있습니다.
- **버전 관리:** 업데이트할 때마다 `package.json`의 `version`과 `CHANGELOG.md`를 올립니다.
