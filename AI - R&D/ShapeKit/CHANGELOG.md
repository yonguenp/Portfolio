# Changelog

## [0.1.0] - Unreleased
### Added
- ShapeImage: uniform, per-corner and pill corner modes, outline, linear gradient, drop shadow, edge softness, circular sprite crop and shape-accurate raycasts, batched with a single material.
- SafeAreaFitter for notches and rounded screen corners.
- ShapePressFeedback for tactile button presses.
- Preset-driven inspector and GameObject > UI > ShapeKit menu items.
- Runtime demo sample with a batching stress test.
- EventSystem creation that matches Active Input Handling (Input System package or legacy Input Manager).
